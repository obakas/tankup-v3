# Prompt 01 — Repo Map

Inspect this repository and produce a concise technical map.

Focus on:
- backend folder structure,
- frontend folder structure,
- docs folder structure,
- current Prisma models,
- current implemented routes,
- current delivery status machine,
- gaps between docs and code.

Do not edit files.

End with:
1. what is already implemented,
2. what is missing,
3. the safest next task.
